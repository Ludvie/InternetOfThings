# Milestone Internet of Things

Repository praktikum IoT mingguan. Setiap minggu disimpan di folder sendiri agar file proyek seperti `platformio.ini`, `src/`, dan diagram Wokwi tidak saling bertabrakan.

## Praktikum

- [Week 1 — ESP32 Environmental Telemetry Node](Week1/README.md)

Untuk menambahkan minggu berikutnya, buat folder `Week2/`, `Week3/`, dan seterusnya. Kerjakan di branch masing-masing, lalu ajukan Pull Request ke `main`.

## Membuka proyek

Untuk build atau menjalankan simulasi Week 1, buka folder `Week1/` langsung di VS Code. Panduan lengkap ada di [Week1/README.md](Week1/README.md).
